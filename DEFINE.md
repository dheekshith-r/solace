# DEFINE: Solace landing page (v1)

Short form, written from `README.md`, `CLAUDE.md` and `SOLACE_BUILD_SPEC.md`. Gaps are marked UNKNOWN.

| Item | Answer |
|---|---|
| Customer | Two readers. (1) A hackathon judge, recruiter or developer who clicks the repo link and wants to see the app in 30 seconds. (2) An adult in India (18+) who feels stretched and wants a calm daily check-in on an Android phone. |
| Scene | They open a link from GitHub, LinkedIn or a message, on a phone or a laptop. They decide in a few seconds whether to install. |
| Pain | Today they only have a README. It shows 3 screenshots and no download button. An APK is hard to trust from a bare link. |
| Outcome | The visitor sees what Solace is, sees it running, sees proof (the certificate), and installs the APK. Target: the download button is visible with no scroll at 375px and 1280px. |
| Mechanism | One static page: name, one-line pitch, real screenshots, the demo video, the certificate, a button to the latest GitHub release, a GitHub link. |
| Difference | Typical wellness-app pages sell a subscription. This page shows a free, open-source app with its safety rules (crisis check, Tele-MANAS 14416) stated, and a public award. |
| Proof | Certificate of Distinction, Solace AI Hackathon, Humanity Founders, 2026 (`HUMANITYFOUNDERS/2026/00514`). User numbers: UNKNOWN. |
| Pricing | Free. It is an open-source hackathon project (MIT), with no business model. |
| Alternatives | Wysa, Headspace, Calm, Tele-MANAS. Competing pages: Play Store listings. |
| Main action | Download the APK. |
| Risks | An APK outside the Play Store looks unsafe: the page must say "Android only, from GitHub Releases" and show the file size. The free Render API sleeps, so the first sign-in can take about a minute. |
| Unknowns | The demo video file (no video with picture found on this PC). More screenshots (only 3 exist). Play Store plans. |

**Magic moment:** the visitor sees Solace's calm Today screen and the "Download APK" button together, in the first screen, within 2 seconds on a mid-range phone.
