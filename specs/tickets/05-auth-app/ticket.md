# 05 Sign up, log in, session, log out (app)

## Must do
- **`src/lib/api.ts`:**
  - Fetch wrapper with base URL, JSON, a timeout, and typed errors using shared Zod schemas.
  - Single-flight refresh on 401, then retries the original request once.
  - Fast offline error: about 4 s timeout, then a quiet retry with backoff while the screen is open.
- **Session store (Zustand):** access token in memory; refresh token in SecureStore; user cached in MMKV.
- **Launch:** if a refresh token exists, refresh behind the splash and go to Today; otherwise onboarding. If the network is down but a cached user exists, open Today from cache and refresh later.
- **Sign up screen:**
  - Name, email and password, with inline validation and a visibility toggle.
  - 18+ checkbox (required).
  - Gemini notice: "Sola's replies are generated by Google Gemini. Please avoid sharing sensitive personal details in this demo."
  - Sends the onboarding goal, timezone and reminders.
- **Log in screen:** email and password, inline errors, a link to Sign up.
- **Log out** (button placed in ticket 12, logic here): revokes server-side, clears SecureStore, MMKV and the query cache, then goes to onboarding.
- TanStack Query client with the MMKV persister.

## Files
`src/lib/*`, `src/features/auth/*`, `app/(auth)/*`, `app/index.tsx`, `app/_layout.tsx` (providers, auth gate).

## Must not touch
Today's visuals, the scene and the API.

## Decisions
Copy is in sentence case. Errors say what happened and what to do, for example: "Couldn't reach Solace. Check your connection and try again."
