1:30 am. If it gets too heavy, help comes first.

Every message you type is checked for crisis words and phrases before any AI call. If one matches, the AI is not called: Solace answers with a fixed, caring message and shows the helpline. No check catches everything, so the helpline also stays in Resources, and it shows even with no network.
